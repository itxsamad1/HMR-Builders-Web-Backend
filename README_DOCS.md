## 🛠️ Viewing Mermaid Diagrams

### In GitHub
✅ **Just view the file!** GitHub automatically renders Mermaid diagrams.

### In VS Code
1. Install extension: "Markdown Preview Mermaid Support"
2. Open FLOWCHARTS.md
3. Press `Ctrl+Shift+V` (Windows) or `Cmd+Shift+V` (Mac)
4. View rendered diagrams

### In Other Editors
- Use [Mermaid Live Editor](https://mermaid.live/)
- Copy diagram code
- Paste and view/edit

## ❓ FAQ

### Q: Which document should I read first?
**A:** Start with `QUICK_REFERENCE.md` for a 15-minute overview, then dive into specific sections of `BUSINESS_LOGIC.md` as needed.

### Q: Can I use these diagrams in presentations?
**A:** Yes! All diagrams in `FLOWCHARTS.md` are created with Mermaid and can be exported as images or SVG.

### Q: How do I search across all documents?
**A:** Use GitHub's search or your IDE's "Find in Files" feature. Search for specific terms like "investment", "wallet", "KYC", etc.

### Q: Are there code examples?
**A:** Yes! `QUICK_REFERENCE.md` has extensive code examples, cURL commands, and testing snippets.

### Q: How often is this updated?
**A:** Documentation should be updated with every significant feature change. Version numbers are at the bottom of each document.

### Q: Can I export these to PDF?
**A:** Yes! Use tools like:
- Markdown to PDF converters
- Print from GitHub (Ctrl+P)
- VS Code with Markdown PDF extension
